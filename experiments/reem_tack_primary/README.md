# TACK 主评测与 P2 细节版 REEM

主评测集固定为 TACK，主指标为检测框 mAP50–95。训练采用相同的混合训练集，含审计通过的 98 张上海地铁裂缝图。改版将更高分辨率的 P2 特征中的横向、纵向和对角局部差异投影到 P3，作为 REEM 的额外残差。

## 验证集选择过程

| 方案 | 每组轮数 | 两个种子的 mAP50–95 变化 |
| --- | ---: | ---: |
| P2 细节与长线门控融合 | 6 | +1.90、−0.93 个百分点 |
| 单独 P2 细节 | 6 | −0.11、+0.71 个百分点 |
| 单独 P2 细节 | 12 | +2.44、−0.26 个百分点 |

三组均未达到原定的两种子都提高的验收线。12 轮阶段验证集的平均变化为 +1.09 个百分点。在首次读取本轮测试结果前另行记录探索性评测方案，包含两套种子的原版和改版全部模型。原筛选回执完整保留。

## TACK 固定测试集，1,898 张

| 随机种子 | 原版 mAP50–95 | P2 细节版 mAP50–95 | 变化 |
| --- | ---: | ---: | ---: |
| 20261224 | 3.21% | 4.02% | +0.81 个百分点 |
| 20261225 | 4.21% | 4.18% | −0.03 个百分点 |
| 两种子平均 | 3.71% | 4.10% | +0.39 个百分点 |

用验证集选定的阈值推到测试集，两组小框检出分别是 35→41 和 42→20，整体无裂缝图误报分别是 89→88 和 81→72。16 张接缝测试图的误报分别是 2→1 和 1→1。这些阈值结果的误报数量在测试集上不同。当前数据支持报告上述设置下的平均 mAP50–95 收益，提升幅度随种子变化，小框检出也有波动。
