# REEM 模块迭代

前一轮在相同无裂缝图误报数下，改版和原版 REEM 的小框检出持平。本轮沿用 TACK 固定划分、归档初始权重和原版对照，继续改变 P3 检测分支中的 REEM。

## 模块改动

| 候选 | 做法 |
| --- | --- |
| 互补门控 | 横向和纵向条带权重一增一减，两个权重之和固定为 2。 |
| 双侧线状对比 | 比较线条中心与两侧的亮暗差异，保留两侧都支持同一条线的响应，再将其加入模块输出。 |
| 局部线状残差 | 在双侧对比基础上减去沿线方向的较长范围平均响应，再将局部差异加入模块输出。 |
| 长线条件门控 | 用局部线状差异调节现有横向和纵向条带的权重。 |
| 逐通道长线门控 | 保留长线条件，改为每个特征通道使用自身的条带响应和局部差异来决定权重。 |

新增权重系数均从 1 开始，新增残差从 0 开始。启动训练前验证整模型输出与原版一致，并检查新增分支有有效梯度。模型只在 P3 检测路径接入这些模块。

## 实验口径

筛选阶段使用两个相同随机种子，每次 8 轮。按每个种子原版 REEM 在置信度 0.25 的无裂缝图误报数设上限，在同一验证集上确定候选的比较点。指标包括小框检出、整体 mAP50–95 及固定的 31 张含明显接缝图片上的图级误报。

TACK 小框沿用标注框短边小于 21.33 像素的口径，IoU 0.50 一对一匹配。验证集有 426 张图，小框 234 个，无裂缝标注图 299 张。接缝清单来自其中 21 个原始帧。

## 筛选结果

下表为相对原版 REEM 的变化。两列数字分别对应随机种子 20261127 和 20261128。

| 候选 | 小框检出变化 | 接缝图误报变化 | mAP50–95 变化 |
| --- | ---: | ---: | ---: |
| 互补门控 | +5、0 | +1、+1 | −0.02、+0.29 个百分点 |
| 双侧线状对比 | +2、−1 | −1、+1 | +0.12、+0.07 个百分点 |
| 局部线状残差 | 0、−2 | 0、+1 | +0.17、+0.12 个百分点 |
| 长线条件门控 | +3、−1 | −1、+1 | +0.45、+0.20 个百分点 |
| 逐通道长线门控 | 0、+1 | 0、+1 | +0.27、+0.36 个百分点 |

五个方案都未达到筛选线。长线条件门控的 mAP50–95 两次均有提升，两组接缝图误报合计持平。在该筛选结果基础上，将其用于 12 轮、两套新种子的探索性复核。
