# FYP-120 隧道裂缝检测

三人毕业设计小组的研究仓库。

## 拟研究问题

复杂背景下的细裂缝漏检，以及接缝、管线和纹理导致的误报。拟比较特征增强与增强控制方法，具体研究方案待导师确认。

## 已有基础

- YOLO11-FR 与 Flexi-YOLO 文献分析及阶段性复现实验。
- 第三周隧道接缝干扰论文的阅读分享，该篇未复现。
- 本地裂缝检测与分割演示原型。
- [TACK 上的 P3 REEM 三组短训](experiments/reem_pilot/) 已完成。保留了改版模块、运行脚本和验证记录。
- [REEM 两种子本机复核](experiments/reem_followup/) 已完成。固定阈值下改版少报，也少检出小框。按相同误报数比较时，小框检出持平。
- [REEM 模块后续迭代](experiments/reem_refinement/) 比较五种结构改动，逐轮记录检出和误报的变化。

历史实验不等同于拟研究方法已验证。实际完成范围以各实验记录为准，不将部分复现称为全文复现。

## 当前阶段

准备开题报告，进一步明确研究空缺、数据条件和实验设计。门控、注意力、条带卷积已有相关研究，具体创新需要文献比较与实验支持。

- `src/`：逐步整理后的项目代码。
