# FYP-120 隧道裂缝检测

三人毕业设计小组的研究仓库。

## 拟研究问题

复杂背景下的细裂缝漏检，以及接缝、管线和纹理导致的误报。拟比较特征增强与增强控制方法，具体研究方案待导师确认。

## 已有基础

- YOLO11-FR 与 Flexi-YOLO 文献分析及阶段性复现实验。
- 第三周隧道接缝干扰论文的阅读分享，该篇未复现。
- 本地裂缝检测与分割演示原型。

历史实验不等同于拟研究方法已验证。实际完成范围以各实验记录为准，不将部分复现称为全文复现。

## 当前阶段

准备开题报告，进一步明确研究空缺、数据条件和实验设计。门控、注意力、条带卷积已有相关研究，具体创新需要文献比较与实验支持。

## 目录

- `src/`：逐步整理后的项目代码。
- `docs/`：项目说明、开题思路和实验协议。
- `experiments/`：实验配置与复现说明。

原始数据、权重和本机环境不直接纳入普通 Git 管理。公开材料须核对来源与授权。当前为仓库初始化，代码迁移尚未完成。
